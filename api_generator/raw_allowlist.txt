# Untyped-field ledger of the generated response models.
# Regenerate with `cargo run -p api_generator -- --openapi <spec> --update-raw-allowlist`.
#
# Each line is a permitted raw JSON (Box<RawValue>) use in opensearch::types:
#
#   namespace:TypeName/field # <form> <cause> -- <review reason>
#
# A member "-" is a whole-type alias, "[additional]" the residual map of a
# struct. Form and cause are computed by the generator. The review reason
# after " -- " is written by hand and kept across updates: an entry whose reason
# is UNREVIEWED fails generation until someone confirms the degradation is
# intended (or fixes the generator / the specification instead).
#
# Causes: no-type (schema declares no type), generic (generic type parameter),
# open-object (object without fixed fields or with untyped additionalProperties),
# untyped-items (array without items), null-only (schema only allows null).
